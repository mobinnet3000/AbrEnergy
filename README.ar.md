# أبر إنيرجي — منصة الطاقة الشمسية المتكاملة

منصة احترافية جاهزة للإنتاج لشركات الطاقة الشمسية، مبنية باستخدام Django REST API و Next.js.

## الميزات

### الواجهة الأمامية
- **Next.js 15** — App Router، مكونات الخادم، عرض ديناميكي
- **TypeScript** — بالوضع الصارم في جميع أرجاء المشروع
- **TailwindCSS v4** — تصميماً بالرموز المخصصة
- **shadcn/ui** — مكتبة مكونات قابلة للاستخدام
- **متعدد اللغات** — الفارسية (يمين إلى يسار)، العربية (يمين إلى يسار)، الإنجليزية (يسار إلى يمين)
- **مسارات مترجمة** — توجيه URL على أساس اللغة
- **مصادقة JWT** — رمز الوصول والتحديث  
- **TanStack Query** — إدارة حالة الخادم
- **Zustand** — حالة العميل (المصادقة)
- **React Hook Form + Zod** — التحقق من صحة النماذج
- **متجاوب** — نقاط الفصل للأجهزة المحمولة والأجهزة اللوحية وسطح المكتب
- **الوضع المظلم** — تبديل السمة تلقائياً

### الواجهة الخلفية
- **Django 5.x** — إطار ويب بايثون احترافي
- **Django REST Framework** — طبقة API قوية
- **JWT** — مصادقة بالرمز المميز
- **RBAC** — 5 أدوار مستخدم
- **إدارة المحتوى** — المقالات، الخدمات، المشاريع
- **مدير الوسائط** — نظام ملفات قابل لإعادة الاستخدام
- **سجل النشاطات** — تتبع كامل للأحداث
- **حاسبة الطاقة الشمسية** — محرك حساب النظام الشمسي
- **الإشعارات** — نظام إشعارات داخل التطبيق
- **Celery** — قائمة انتظار المهام غير المتزامنة
- **PostgreSQL** — قاعدة البيانات الأساسية
- **Redis** — تخزين مؤقت ووسيط الرسائل
- **Docker** — حاويات متعددة الخدمات

## التثبيت

### الواجهة الخلفية
```bash
cd AbrEnergy
python -m venv .venv
pip install -r requirements/dev.txt
python manage.py migrate
python manage.py seed_data --force
python manage.py runserver
```

### الواجهة الأمامية
```bash
cd abr-energy-frontend
npm install
npm run dev
```
