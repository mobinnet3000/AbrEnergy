# ابر انرژی — پلتفرم تمام‌عیار انرژی خورشیدی

یک پلتفرم حرفه‌ای و آماده تولید برای شرکت‌های فعال در حوزه انرژی خورشیدی، ساخته شده با Django REST API و Next.js.

## ویژگی‌ها

### فرانت‌اند
- **Next.js 15** — App Router، کامپوننت‌های سرور، رندر داینامیک
- **TypeScript** — با تنظیمات strict در سراسر پروژه
- **TailwindCSS v4** — استایل‌دهی با توکن‌های طراحی سفارشی
- **shadcn/ui** — کتابخانه کامپوننت‌های قابل دسترس و قابل استفاده مجدد
- **چندزبانه** — فارسی (راست‌چین)، عربی (راست‌چین)، انگلیسی (چپ‌چین)
- **آدرس‌های محلی‌شده** — مسیرهای URL مبتنی بر زبان
- **احراز هویت JWT** — توکن دسترسی و توکن بازخوانی با چرخش خودکار
- **TanStack Query** — مدیریت state سمت سرور
- **Zustand** — state سمت کلاینت (احراز هویت)
- **React Hook Form + Zod** — اعتبارسنجی فرم با تایپ ایمن
- **واکنش‌گرا** — نقاط شکست موبایل، تبلت، دسکتاپ
- **حالت تاریک** — تغییر تم بر اساس تنظیمات سیستم

### بک‌اند
- **Django 5.x** — فریم‌ورک قدرتمند پایتون
- **Django REST Framework** — لایه API قدرتمند
- **JWT** — احراز هویت با توکن
- **RBAC** — ۵ نقش کاربری
- **مدیریت محتوا** — مقالات، خدمات، پروژه‌ها، گالری، تماس‌ها
- **مدیریت رسانه** — سیستم فایل قابل استفاده مجدد
- **گزارش فعالیت** — ثبت کامل رویدادها
- **محاسبه‌گر** — موتور محاسبه سیستم خورشیدی خارج از شبکه
- **اعلان‌ها** — سیستم اعلان درون برنامه‌ای
- **Celery** — صف وظایف ناهمزمان
- **PostgreSQL** — پایگاه داده اصلی
- **Redis** — کش و صف پیام
- **Docker** — کانتینرسازی چند سرویسه

```
│   │   ├── contacts/       # فرم‌های تماس
│   │   ├── gallery/        # گالری تصاویر

│   ├── src/

│   └── public/             # فایل‌های ایستا
```

## نصب و راه‌اندازی

### پیش‌نیازها
- Python 3.12+
- Node.js 20+
- PostgreSQL 16 (یا SQLite برای توسعه محلی)

### بک‌اند

```bash
cd AbrEnergy
python -m venv .venv
source .venv/bin/activate
pip install -r requirements/dev.txt
python manage.py migrate
python manage.py seed_data --force
python manage.py runserver
```

### فرانت‌اند

```bash
cd abr-energy-frontend
cp .env.example .env
npm install
npm run dev
```
