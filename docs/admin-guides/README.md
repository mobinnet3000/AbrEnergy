این دایرکتوری شامل راهنماهای مستقل و تفصیلی برای هر یک از سطوح دسترسی و نقش‌های سامانه ابر انرژی می‌باشد. هر راهنما شامل دسترسی‌های مجاز، محدودیت‌ها، نحوه ورود، سناریوهای گام‌به‌گام کاری، هشدارهای امنیتی و شیوه تعامل با پنل مدیریت است.

## اصول عمومی کاربری پنل مدیریت (General Operational Principles)

1. **زبان پیش‌فرض:** پنل مدیریت به صورت فارسی و راست‌چین (RTL) طراحی شده است.
2. **احراز هویت و نشست‌ها:** توکن‌های دسترسی معتبر ۳۰ دقیقه و توکن‌های تجدید نشست ۷ روزه هستند. در صورت عدم فعالیت طولانی، سامانه جهت امنیت مجدداً درخواست ورود خواهد کرد.
3. **تفکیک مسئولیت‌ها (Least Privilege):** هر نقش صرفاً به ابزارها و ماژول‌های مرتبط با وظایف تخصصی خود دسترسی دارد و سایر ماژول‌ها پنهان یا غیرفعال هستند.
4. **ردگیری عملیات (Audit Trail):** تمامی عملیات ایجاد، ویرایش، انتشار و حذف محتوا به همراه شناسه کاربر و زمان دقیق در لاگ فعالیت‌های سیستم (`ActivityLog`) ثبت می‌شوند.
