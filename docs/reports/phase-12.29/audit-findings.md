## 2. Root Cause Analysis Summary

1. **Brand Identity:** The presence of Next.js default placeholders was due to leftover scaffolding from the initial frontend project creation. Resolution completely excised placeholders, configured the authentic `abar-energy-logo.png` with strict dimensions, and added dynamic locale-aware routing.
2. **Dropdown Enum Glitch:** The root cause was Base UI `<SelectPrimitive.Value>` rendering raw string values when children were pure JSX elements without an options registry. Resolution injected a dynamic React context registry that binds item keys to translated labels immediately upon component mount.
3. **Security Throttling:** Auth and inquiry endpoints lacked burst rate limits beyond broad hourly throttles, presenting brute-force and scraping attack surface. Resolution added dedicated minute-rate throttles with graceful test fallbacks.
4. **SEO & GEO:** Content managers had no visibility into meta tag completeness or keyword search footprint. The newly architected `/admin/seo` provides real-time deterministic score calculations, keyword tracking, CSV export, and an AI GEO search optimization checklist.
